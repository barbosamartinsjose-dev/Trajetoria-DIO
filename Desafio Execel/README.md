# 🎮 Dashboard de Vendas - Xbox Subscriptions

**Descrição:** Este projeto transforma dados brutos de assinaturas (Core, Standard, Ultimate) em um dashboard executivo interativo. O objetivo é analisar o faturamento de planos anuais e a adesão de serviços adicionais (EA Play e Minecraft).

## 🛠️ Tecnologias Utilizadas
* **Microsoft Excel:** Processamento de dados e visualização.
* **Fórmulas Avançadas:** `SOMASES`, `SOMASE` e vínculos dinâmicos de formas.
* **Data Storytelling:** Organização de KPIs para tomada de decisão.

## 📊 Perguntas de Negócio Respondidas
1. Qual o faturamento total dos planos anuais?
2. Como a auto-renovação impacta a receita recorrente?
3. Qual o market share dos adicionais (EA Play vs Minecraft) por categoria de plano?

## 📁 Como visualizar
1. Baixe o arquivo `Xbox.xlsx`.
2. Abra no Excel e utilize as **Segmentações de Dados** (Slicers) para filtrar os resultados por tipo de plano ou renovação.
